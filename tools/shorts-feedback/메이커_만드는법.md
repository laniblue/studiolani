# 쇼츠제작실.html 다시 만들기 (개발용)
- 소스: `maker_src.html` (글씨체·템플릿은 `{{FONT_*}}`, `{{TEMPLATE_PNG}}` 자리)
- 자산: `maker-assets/fonts/*.woff2` (한글·일본어만 남긴 서브셋), `maker-assets/template.png`
- 빌드: 아래 파이썬으로 base64 넣어서 `쇼츠제작실.html` 생성
```python
import base64; M='maker-assets'; b=lambda p: base64.b64encode(open(p,'rb').read()).decode()
s=open('maker_src.html',encoding='utf-8').read()
for k,f in [('FONT_BM','fonts/BMDOHYEON.woff2'),('FONT_NARR','fonts/KoreanCNMM-narration.woff2'),('FONT_GRIUN','fonts/GriunYeeun-Rg.woff2'),('FONT_HS','fonts/HSHwalkongSerif-Regular.woff2'),('FONT_MPLUS','fonts/MPLUSRounded1c-Black.woff2'),('TEMPLATE_PNG','template.png')]:
    s=s.replace('{{'+k+'}}',b(f'{M}/{f}'))
open('쇼츠제작실.html','w',encoding='utf-8').write(s)
```
- 규격은 소스 맨 위 `SPEC`(화이트/블랙/일본어)에 있음 = 정답지·white-template-ko-animal.md 값. 규칙이 바뀌면 SPEC 고치고 다시 빌드.

## 클로드 코드(구독) 연결 (2026-11-02, 기본)
- `server.py`가 `POST /api/claude {prompt, system, search}` 를 받아 맥의 `claude -p --output-format text --append-system-prompt … [--allowedTools WebSearch WebFetch]` 로 실행하고 `{text, seconds}` 를 돌려줌. `GET /api/claude/status` 로 연결 확인.
- 페이지는 `KEYS.mode` 가 `code`(기본)면 서버로, `api`면 Anthropic API로 직접. file:// 로 열었으면 `http://localhost:8765` 로 붙음.
- `제작실_켜기.command` = 서버 켜고 브라우저 열기. 서버 `/` 는 `쇼츠제작실.html` 을 서빙.
- ⑤ 완성 탭·검수·메모는 삭제. ④ 안 「편집 완료 → 최종 영상 만들기」 → `#finalCard` 에 영상(blob)·썸네일·상위 3개 비교(`renderFinalCmp`, i.ytimg 썸네일)·복사 버튼.

## ④ 편집기 구조 (2026-11-02, VLLO식)
- 가운데 미리보기 → 재생 컨트롤 → 도구줄(자르기·시작/끝=지금·복제·삭제·+자막·🎙음성·🔍줌) → 3트랙 타임라인(`#trkV` 영상 / `#trkC` 자막 / `#trkA` 음성, `PPS()` 픽셀/초, `#zoom` 0=맞춤) → 선택한 장면의 속성판(`#scenes`, 장면 하나만) → 클로드 프롬프트 → 「편집 완료」.
- 자막 블록 끌기 = `c.s/c.e` 이동·트림, 음성 블록 끌기 = `voice.at`. 모두 `snap()` 되돌리기 가능.
- 오른쪽 `#verCard`: `VERS[]`에 렌더마다 {url, thumbs, scenes} 추가, 탭으로 전환, 다운로드, 「이 버전 대본으로」 복원. 새로고침하면 버전은 사라짐(blob).
- 아래 `#finalCard`: 우리 vs 상위 3개 비교 + 제목/출처/해시태그/업로드 글 복사.
