# 쇼츠메이커.html 다시 만들기 (개발용)
- 소스: `maker_src.html` (글씨체·템플릿은 `{{FONT_*}}`, `{{TEMPLATE_PNG}}` 자리)
- 자산: `maker-assets/fonts/*.woff2` (한글·일본어만 남긴 서브셋), `maker-assets/template.png`
- 빌드: 아래 파이썬으로 base64 넣어서 `쇼츠메이커.html` 생성
```python
import base64; M='maker-assets'; b=lambda p: base64.b64encode(open(p,'rb').read()).decode()
s=open('maker_src.html',encoding='utf-8').read()
for k,f in [('FONT_BM','fonts/BMDOHYEON.woff2'),('FONT_NARR','fonts/KoreanCNMM-narration.woff2'),('FONT_GRIUN','fonts/GriunYeeun-Rg.woff2'),('FONT_HS','fonts/HSHwalkongSerif-Regular.woff2'),('FONT_MPLUS','fonts/MPLUSRounded1c-Black.woff2'),('TEMPLATE_PNG','template.png')]:
    s=s.replace('{{'+k+'}}',b(f'{M}/{f}'))
open('쇼츠메이커.html','w',encoding='utf-8').write(s)
```
- 규격은 소스 맨 위 `SPEC`(화이트/블랙/일본어)에 있음 = 정답지·white-template-ko-animal.md 값. 규칙이 바뀌면 SPEC 고치고 다시 빌드.
