# 쇼츠 피드백 페이지 쓰는 법

## 처음 한 번
1. 이 폴더(`shorts-feedback`)를 맥 아무 데나 둔다 (예: 바탕화면).
2. 폴더 안 `피드백페이지_켜기.command`를 **오른쪽 클릭 → 열기** (처음만. 그다음부턴 더블클릭).
   - "python3를 설치할까요?" 창이 뜨면 설치 누르기 (맥 기본 제공, 몇 분 걸림).
3. 검은 창에 주소 두 개가 뜬다.
   - 맥: `http://localhost:8765`
   - 아이패드: `http://192.168.x.x:8765` (같은 와이파이여야 함)

## 매번
1. 컨펌할 영상을 `컨펌본/` 폴더에 넣는다.
2. 맥에서 `.command` 더블클릭 → 주소 열기 (아이패드는 사파리에 주소 입력, 홈 화면에 추가해 두면 편함).
3. 영상 보다가 멈추고 → 아래 칸에 피드백 쓰고 → **이 시간에 피드백 저장**.
4. 오른쪽 목록에 시간이랑 같이 쌓인다. 누르면 그 장면으로 이동.
5. 피드백은 `피드백/영상이름.json`에 저장된다.

## 클로드한테 반영시키기
- 클로드한테 **"피드백 반영해줘"** 라고 하면 `피드백/*.json`을 읽고 고친 뒤, 반영한 항목에 `done: true`와 한 줄 메모(`reply`)를 넣는다. 페이지를 새로고침하면 ✓ 로 보인다.
- 클로드가 이 폴더를 읽을 수 있어야 하니, 클로드 세션을 이 폴더(또는 상위 폴더)에서 열거나 json 파일을 올려 준다.

## 안 열릴 때
- 아이패드에서 안 열리면: 맥이랑 같은 와이파이인지, 맥 방화벽에서 python 허용했는지 확인.
- 외부에서 못 열게 막혀 있음(같은 와이파이만). 더 막고 싶으면 켤 때 `PIN=1234 python3 server.py` 로 켜고 주소 뒤에 `?pin=1234` 붙이기.
- 다른 포트: `PORT=9000 python3 server.py`
