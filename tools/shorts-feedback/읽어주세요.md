# 쇼츠 제작실 쓰는 법

## 제일 쉬운 방법 (아이패드·맥 어디서나, 클로드 로그인만)
- claude.ai에 로그인한 상태로 이 주소를 연다: **https://claude.ai/artifact/3G78zZAasi8g3cMXKUmVgr**
- 처음 클로드를 쓰려고 할 때 "이 아티팩트가 Claude를 쓰게 허용할까요?" 창이 뜨면 허용. 유튜브 대조(같은 원본 찾기)는 claude.ai 커넥터에 Uplika가 연결돼 있으면 자동으로 쓴다.
- 구독 사용량으로 돌아가고, 맥이 켜져 있을 필요 없음. 아이패드 사파리 → 공유 → 홈 화면에 추가 하면 앱처럼 쓴다.
- 영상 파일은 아이패드 파일 앱에서 고르면 된다. 완성 영상·썸네일은 「다운로드」 누르면 저장 확인 창이 뜬다.


## 다른 방법: 맥에서 클로드 코드로 (맥 파일 버전)
1. 이 폴더(`shorts-feedback`)를 맥 아무 데나 둔다 (예: 바탕화면).
2. 맥에 클로드 코드가 깔려 있고 `claude` 로그인(구독)이 되어 있어야 한다. 터미널에서 `claude` 쳐서 열리면 OK.
3. `제작실_켜기.command`를 **오른쪽 클릭 → 열기** (처음만. 그다음부턴 더블클릭). 브라우저가 자동으로 열린다.
   - "python3를 설치할까요?" 창이 뜨면 설치.

## 매번
1. `제작실_켜기.command` 더블클릭 → 제작실이 열림 (`http://localhost:8765/`).
   - 아이패드: 검은 창에 뜬 `http://192.168.x.x:8765/` 를 사파리에 입력 (같은 와이파이, 맥이 켜져 있어야 함).
2. ① 자료: 언어·템플릿 고르고, 쇼츠 링크 넣고, 원본 영상 넣고 → **클로드 분석 시작**. 1~3분.
   - 「클로드 연결」은 기본이 **클로드 코드(구독)**. 맥의 claude가 돌리니까 추가 요금 없음. 맥 없이 쓰려면 API 키로 바꿀 수 있음(따로 과금).
3. ② 분석: 같은 원본 목록·카테고리 공식·상위 3개 비교 + 영상 바로 보기. 마음에 안 들면 「다시 분석」.
4. ③ 각색: 제목 하나, 대본 하나 고르기. 「다시 요청」에 한 줄 쓰고 Enter 하면 새 후보가 바로 옴.
5. ④ 제작·편집: 타임라인·자막·음성 싱크 편집. 미리보기 아래 칸에 "덥석 0.3초 더 길게" 같이 쓰고 Enter → 바로 반영. 되돌리기 ↶. **고칠 게 여러 개면 번호 매겨서 한 번에** (1. … 2. … 3. …) — 사용량 아끼는 법.
   - 음성 파일은 장면마다 🎙 붙이고 「지금」으로 시작 맞춤.
   - **편집 완료 → 최종 영상 만들기** 누르면 아래에 최종 영상 + 썸네일 A/B/C + 상위 3개 비교가 뜨고, 「영상 다운로드」로 저장. 제목·출처·해시태그는 버튼으로 복사.
6. 「확정본 복사 → 스킬 저장」을 클로드한테 붙여넣으면 스킬에 저장된다.

## 안 될 때
- "꺼져 있어" 라고 뜨면: 맥에서 `제작실_켜기.command`가 켜져 있는지 확인.
- "claude 명령을 못 찾았어": 터미널에서 `which claude` 확인. 없으면 클로드 코드 설치.
- 아이패드에서 안 열리면: 같은 와이파이인지, 맥 방화벽에서 python 허용했는지 확인.
- 외부에서 못 열게 막혀 있음(같은 와이파이만). 더 막고 싶으면 `PIN=1234 python3 server.py` 로 켜고 주소 뒤에 `?pin=1234`.
- 옛 피드백 페이지는 `http://localhost:8765/index.html` 에 그대로 있음.
