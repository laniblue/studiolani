쇼츠 제목은 터진 버전 제목들을 표로 비교해 **공통 요소를 전부 그대로** 따른다. 예: 이름 바꾼 엄마 쇼츠 — 터진 5개 모두 "원인(딸이 너무 부름) + 이름 바꾼 엄마"를 말하고 호칭은 ママ → 우리 제목도 이름 바꾼 걸 말하고 ママ를 쓴다. "母がとった手段"처럼 공통으로 말하는 걸 숨기거나 호칭을 바꾸면 안 된다. 바꾸는 건 단어·표현뿐. 숨기는 건 결말(그래도 계속 불림)만.

**Why:** 대표님 2026-10-27 「야 이게 중요해. 공식 왜 안 따라가????」 — 비교표에서 우리 제목만 '숨김'·'母'였음.

**How to apply:** 제목 후보를 내기 전에 터진 제목 비교표(1줄 원인 / 2줄 결과 / 말하는 것 / 호칭)를 만들고, 후보마다 공통 요소를 다 지켰는지 칸으로 확인한 뒤 보여 준다. 대표님이 고른 제목도 공식에서 벗어나면 그 자리에서 말한다. [[shorts-approved-2026-10-26]] [[shorts-script-ok-first]]

- 단어는 **쉬운 말**로(중학생도 아는 일상어). 連呼·呼び立て·鳴りやまない 같은 어려운 단어 금지 (대표님 2026-10-27 "쉬운 단어 쓰라고").
- 후킹은 따로 만들지 않는다. **조회수 상위 3개 제목의 결(말투·구성)을 그대로** 따르고 단어만 바꾼다. 連打·リセット 같은 내 기교 금지 (대표님 2026-10-27 "상위 세 개가 결이 비슷하잖아, 그렇게 하라고").
- **업로드 제목 = 영상 위 제목 그대로**(두 줄을 붙여서). 상위 3개 모두 업로드 제목이 화면 제목과 같음(2026-10-27 확인). 따로 새 업로드 제목 만들지 않기 (대표님 "우리 제목 뭔데..?"). 업로드 문구 순서: 제목 → 元動画 : 출처 → 해시태그.
- **길이도 1위 화면 제목과 같게** — 줄마다 띄어쓰기 포함 1위 +2자까지, 설명 덧붙이지 않기 (대표님 2026-10-29 「너무 길게 나오는 거 아님? 원본에서 내용 변경 느낌」, 「평생 어둠 속에 사는 강아지를」 지적). 오피스 replan-now.py hook_fits 가 길면 탈락시킴, lani-studio-run·run-2 규칙 5번에도 넣음.
