쇼츠(일본어 등 외국어 제작 포함)를 만들거나 고치면, 각색한 **제목과 자막 내용 전체를 한국어 / 일본어 텍스트로** 채팅에 같이 준다. 줄마다 **해설 / 인물(누구) / 속마음**을 구분해서 표시한다.

**Why:** 대표님 지시(2026-10-21): "항상 이렇게 주는게 기본이다. 기억하렴". 일본어만 보고는 내용을 검수할 수 없다.

해시태그에는 "웃긴 영상" 태그를 항상 넣는다: 일본어 `#面白い動画`, 한국어 `#웃긴영상` (대표님 지시 2026-10-22). 출처는 `元動画 : 〇〇` 형식.

**형식 (2026-10-24 대표님):** 영상 줄 때마다 한글 텍스트로 `제목` / `각색 내용`(한두 줄) / `화자 : 대사` 순서로, 복사하기 좋게 코드 블록에 넣어서 준다(2026-10-24). 참고 영상 내용(제목·자막)과 각색 내용(제목·각색 내용·화자 : 대사)은 코드 블록을 따로 나눠서 나란히 준다(2026-10-24). 화자 표시는 간단하게 '아내 : / 남편 : / 해설 : / 강아지 :' 처럼 이름만 (대괄호·'사람 -'·'속마음' 같은 복잡한 표시 금지, 2026-10-24). 대사는 화면에 나오는 단위(2~4어절)로 줄바꿈해서 적고, 각색 텍스트에는 편집 내용(흑백·스티커 등)을 적지 않는다(2026-10-24). '각색 내용' 요약도 한 문장씩 줄바꿈(2026-10-24).

**How to apply:** 영상 보낼 때마다 표(시간 · 구분 · 일본어 · 한국어 뜻) + 헤더 제목 한/일. 편집은 "예시"를 그대로 넣지 말고, 터진 쇼츠들을 직접 분석해 그들이 쓴 편집 방식(확대 위치·빈도·스티커·효과)을 따라 한다. [[conti-self-check]]

- 대본 공유 때 **모든 줄**(이름만 외치는 딸 대사·괄호 리액션 포함)에 한국어 뜻을 붙인다. 이름이라고 빼지 않는다 (대표님 2026-10-27 "딸 해석은 왜 다 안 적어주니").
