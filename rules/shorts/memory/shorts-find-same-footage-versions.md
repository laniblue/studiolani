"쇼츠 제작해줘 + 참고 영상 링크 + 원본 영상 파일"이 오면, 제작 전에 **같은 장면(원본)을 가져다 각색한 다른 쇼츠를 최대한 전부** 찾아서 먼저 보여 준다. 원본 출처 찾기가 아님.

**Why:** 대표님 2026-10-26 "이렇게 먼저 찾아서 줘. 알겠냐?" — 할머니 농구(Ross Smith) 쇼츠 때 11개 찾아 준 방식이 정답.

**How to apply:**
- ego-browser로 유튜브 쇼츠 필터 검색(&sp=EgIYAQ%253D%253D), 한·일·영(+스페인·중국어)으로 장면을 묘사하는 검색어 20~30개, 스크롤 3번씩.
- 제목으로 1차 거르고, 후보 썸네일(i.ytimg.com/vi/ID/hq2.jpg, 가운데 202px 크롭)을 격자로 붙여 눈으로 대조 → 맞는 것만 hq1~3으로 재확인.
- yt-dlp --skip-download -j 로 조회수·길이·채널·날짜 확인.
- 결과: 언어별 표(조회수·제목·링크), 100만+ 표시, 원본을 그대로 다시 올린 영상(각색 없음)은 제외, 못 찾은 범위(틱톡·인스타)는 "확인 못 함".
- 찾는 목적 = **터진 버전들 구조를 분석해서 내 쇼츠에 적용**(대표님 2026-10-26 "알겠어?????"). 구조 3가지: ① 제목 훅 ② 내용(자막 대사·해설 흐름) ③ 편집 스타일(컷편집·장면전환·자막 글자 애니메이션·편집효과·스티커 등). 버전별로 비교표 → 내 영상에 뭘 가져올지까지.
- 그다음 언어 묻기 + 다운로드 허락 받기. [[shorts-confirmed-workflow]] [[use-ego-lite-browser]]
- **비교표(1·2·3위)도 같은 원본 버전만** — 같은 분야 영상으로 채우지 않음, 모자라면 찾은 만큼만 (대표님 2026-10-29 「이 영상이랑 동일한 영상을 쓴 거 찾는 거라 했잖아」 · 팬케이크·같은 분야 2·3위 지적). 오피스 viral-uses.py 가 2026-10-29부터 확정 방식(장면 검색어 30개·쇼츠 필터·스크롤 3번·hq1~3·재업로드 제외·전부+100만+)으로 찾음.
- 같은 장면 판정은 특징점 맞은 점 40 이상(2026-10-29 실측: 같은 장면 67·78·101 / 다른 영상 20~29). 찾은 뒤 work/same-footage/grid.jpg 를 꼭 눈으로 확인 — 한국어·일본어, 대표님·동생 작업 모두 같은 방식.
