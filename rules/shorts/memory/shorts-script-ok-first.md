쇼츠는 **렌더 전에 내용부터 공유 → 대표님 오케이 → 제작**. 아니라고 하면 내용 수정 후 다시 공유 (2026-10-24 대표님).

**Why:** 갱쥐 일본어 쇼츠 v2를 바로 렌더했는데, 참고 영상(아내를 지킬 서비스견 강아지 · 방탄조끼 · 지킬 준비 · 하품)과 비교하면 이야기 핵심이 빠지고 「캔 홀더」 같은 이상한 대사만 남았다.

**How to apply:** 대본을 쓰면 참고 영상 자막과 나란히 놓고 이야기 흐름(누구를 위해·무엇을·웃음 포인트·끝맺음)이 살아 있는지 먼저 본다. 그다음 코드 블록 하나(제목 / 각색 내용 / 화자 : 대사, 한국어 뜻 포함)로 공유하고 오케이를 기다린다. [[shorts-confirmed-workflow]] [[shorts-script-text-ko-ja]]

- **오케이 받은 대본 문장은 내 마음대로 바꾸지 않는다.** 대표님이 바꾸라고 한 줄만 바꾸고, 내가 제안만 하고 답 못 받은 안(예: 노이로제 해설)은 넣지 않는다 (2026-10-27 "이걸로 하라 랬잖아").
