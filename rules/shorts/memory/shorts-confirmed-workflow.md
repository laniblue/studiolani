쇼츠는 video-studio 스킬 맨 위 "★ 쇼츠 만들기 확정 순서"대로 만든다 (2026-10-22 대표님 오케이, 오피스·동생 화면 공통).
링크 → 원본 → 같은 주제(=웃긴 영상·강아지·고양이 같은 큰 장르, 좁히지 않기)로 터진 100만+ 싹 찾기(같은 원본 쓴 쇼츠 찾기 아님 — 2026-10-24 대표님 지적, 2개 찾고 멈추지 않기) → 자막 전부 비교 → 각색(번역 아님, 대사·표현이 터진 쇼츠와 한 줄도 겹치면 안 됨) → 영상 순서대로 합친 대사 텍스트 → 한국어 템플릿(아래 띠 없음) · 효과음 없음 · 박힌 글자 모자이크 · 말할 때만 자막 · 끝 검은 화면 자르기 → 점검 → 영상+대사 텍스트 같은 버전.

**Why:** 대표님이 번역만 한 버전("터진 거 분석했다며", "겹치면 안 됨"), 효과음, 아래 검정 띠, 자막 싱크, 뉴스·사극 말투를 차례로 지적함.

**How to apply:** 해설은 터진 쇼츠처럼 자연스러운 3인칭 존댓말(~죠/~습니다), 동물 속마음은 귀여운 반말, 제목은 결말 숨기기, 마지막 해설은 짧게. 최종 파일과 대사 텍스트는 같은 버전인지 확인하고 드린다. [[shorts-template-by-language]] [[shorts-script-text-ko-ja]]

추가(2026-10-22): **쇼츠는 단계 제작** — ① 컷 편집(Whisper+무음, 단어 경계 컷, 반복은 마지막 테이크, 다시 받아쓰기 검사, 체크리스트 5) → 확인 → ② 자막 2~4어절·모션 + hyperframes check + 미리보기 → 확인 → ③ 최종 검사 후 고화질 렌더. 음악·효과음 없음. 마음에 드는 수정은 📌 규칙으로 저장(edit-feedback.md, 언제·어떻게·예외). 자세한 건 video-studio SKILL ★ 쇼츠 단계 제작 순서.

추가(2026-10-24): **각색 영상은 항상 30초 이내, 대표님이 보낸 원본(발견한 쇼츠) 길이보다 길면 안 됨.** 대본 쓸 때부터 길이를 맞춰 한 번에 렌더.

추가(2026-10-24): **터진 영상 주제(검색어)는 대표님이 정한다.** 정해 준 말(예: 웃긴 영상 / 웃긴 해외영상)을 한국어·일본어·영어로만 옮겨 검색하고, 내 마음대로 단어(남편·부부·강아지 등)를 붙이지 않는다. 100만+ 이면서 자막 각색이 있는 것으로 최소 20개 분석 → 제목 훅·자막 구성 반영 → 대본 먼저 공유.
