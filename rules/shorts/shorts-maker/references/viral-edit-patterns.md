# 터진 쇼츠 편집 패턴 (직접 본 것만 · 계속 쌓는다)

대본을 쓸 때 scene.fx · lines[].anim 은 **여기 적힌 "어떤 순간에 무엇을"** 을 따라 필요한 곳에만 넣는다.
새로 분석한 터진 쇼츠가 생기면 맨 아래 "관찰 기록"에 한 줄씩 추가한다 (보지 않은 건 적지 않는다).

## 쓰는 양
- 효과가 들어간 장면은 전체의 1/3 안쪽. 같은 효과를 연달아 쓰지 않는다.
- 4~6초에 한 번은 무언가 움직이게 (자막 애니메이션 포함) — `references/dynamic-edit.md`.
- 효과음은 쓰지 않는다 (대표님 2026-10-22).
