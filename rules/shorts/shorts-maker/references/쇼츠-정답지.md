## 1. 순서 — 건너뛰지 않는다 (✋ = 대표님·동생 확인 기다림)

1. **링크·원본** — 링크만 와도 원본은 직접 찾는다(원작자 인스타·채널 → 틱톡·페북). 못 찾으면 "확인 못 함". **원본 화질 가로 1080 미만이면 바로 말하고 고화질 요청.**
2. **같은 원본 버전 전부 찾기** — 한·일·영 장면 묘사 검색어 30개, 유튜브 쇼츠 필터, 스크롤 3번, 썸네일 hq1~3 격자 눈 대조(특징점 40+), 조회수는 yt-dlp. 그대로 재업로드는 뺌. 언어별 표(조회수·제목·링크, 100만+ 표시). 틱톡·인스타는 "확인 못 함".
3. **상위 3개 분석** — 같은 원본 버전 조회수 상위 3개만(같은 분야 영상으로 채우지 않음, 모자라면 찾은 만큼만). 4fps 시트·글자 인식(일본어 ja-JP)·whisper(해설 음성 받아쓰기용만)로: 줄마다 자막 대조표 / 편집 전면 비교표(길이·첫 장면·컷 수·전환·확대·**좌우반전**·삽입 영상·끝 화면·화면 배치·제목 색·자막 색/등장·해설 음성·원본 소리·음량) / 썸네일 표. 큰 카테고리 공식(`shorts/_분석/`)도 같이.
4. **제목 후보** — 아래 3절. ✋ 고르기.
5. **대본** — 아래 4절. 1·2·3위 vs 우리 비교표(한글 뜻만, 맨 위 제목 줄)로 보여 줌. ✋ 오케이.
6. **해설 음성 받기** — 음성 없이 해설 영상 만들지 않음. ✋ 음성 파일.
7. **장면 맞추기(손으로)** — 원본 0.5~1초 시트를 **전부 직접 보고** 줄마다 원본 구간을 정한다(추정 시간 금지). 대사 장면은 실제 말하는 구간(말소리·입 모양), 해설 장면은 해설이 말하는 행동이 보이는 구간, 원본 시간 순서는 1위 박자대로. 다른 컷 프레임이 끼지 않게, 얼굴이 잘리지 않게.
8. **미리보기 렌더** → **눈으로 검수**(9절 표 전부) → 문제 있으면 7로 돌아가 고침(스스로 고쳐서 통과, 경고만 띄우고 넘기지 않음). ✋ 미리보기 확인.
9. **최종 렌더 한 번** → 9절 검수 다시 → 전달(10절).

## 2. 소재 고르기
- **한국어** = 강아지·고양이 영상만, 한국·미국·일본 쇼츠 섞어서, 100만+.
- **일본어** = 일본·한국의 해외 웃긴 영상(번역형), 100만+. 인플루언서·크리에이터 본인 셀카·방송·콩트·먹방 제외 → 일반인 상황(몰카·CCTV·가족·가게).
- 답을 기다리는 이야기(사건 → 새 정보 → 결말 한 방), 리액션 반복 모음 X. 일본어는 갭모에 우선.
- 검색 주제는 대표님이 정한 말만 옮겨 검색(내 단어 붙이지 않음).

## 3. 제목
- 상위 3개 제목의 **결 그대로**: 공통으로 말하는 것·호칭은 그대로, 단어만 바꿈, **결말만 숨김**. 내 기교·후킹 단어 금지, 쉬운 일상어.
- 2줄, 줄마다 길이 = 1위 화면 제목 +2자까지(띄어쓰기 포함).
- 한국어: 동물 단어(강아지·댕댕이·고양이·냥이) + 궁금증 끝맺음(~의 반응·최후·이유·순간).
- 일본어: [가족·관계] + [행동·상황] + [주인공(ママ·夫·娘)], 카드(명사)로 끝.
- 업로드 제목 = 화면 제목 그대로(두 줄 붙여서).

## 4. 대본
- 줄 순서·뜻 = 상위 1·2위 공통 흐름, **표현만** 바꿈(줄마다 기계 대조 0.7 미만). 번역 금지. 없는 대사·인물 지어내지 않음.
- 말투는 1·2위처럼 친근하게. 일본어 해설은 2위 말투(母親·~んですが·~そうです·~んですね). 한국어 해설은 자연스러운 3인칭 존댓말(~죠/~습니다), 동물 속마음은 귀여운 반말.
- 참고 영상의 장면·웃음 포인트는 다 담는다. 해설 반드시 넣음(상황 → 반전 예고 → 대사 → 리액션 → 끝 펀치).
- 첫 3초에 "뭐지?" 미스터리. 결말 장면을 앞으로 당기지 않음. 같은 리액션 반복 금지.
- 길이 20~23초 목표, 30초 이하, 참고 영상보다 길지 않게. 펀치라인에서 바로 끝.
- **오케이 받은 문장은 절대 내 마음대로 안 바꿈.** 고치라는 줄만.
- 공유 형식: 코드 블록 하나에 순서대로 `화자 : 원문 (한글 뜻)` + 제목. 모든 줄에 뜻(이름 외침 포함). 화자는 이름만(엄마 : / 해설 :).
- 화자는 목소리 높낮이(남 100~160Hz, 여 190~290Hz)·입 모양으로 확인. 애매하면 글로 묻는다(추정 금지, ❓ 기호 금지).

## 5. 편집 (언어 공통)
- **좌우반전은 상위 3개가 했을 때만**(셋 다 안 했으면 안 함). 글씨 보이는 장면은 반전 안 함.
- 컷은 상위 3개처럼: 말 없는 빈 곳 잘라 빠르게. 같은 앵글 점프컷은 얼굴 클로즈업(약 2배)으로 바꿈. 확대는 컷에서 "확"(밀어 들어가는 줌 금지).
- **효과음·배경음 없음. 전환 효과 없음. 화면 어둡게 하는 효과 금지. 스티커 없음.** 편집 효과 넣기 칸 없음.
- 시작은 첫 장면부터 바로. 원본 박힌 글자는 제목 칸 뒤로 숨기거나 흔적 없이 지움.
- 대사 장면은 앞뒤·말 사이 **0.8초 넘는 무음만** 잘라 냄(앞뒤 0.25초 남김), 자르고 1초보다 짧아지면 안 자름. 장면 끝에서 말이 이어지면 말 끝까지(최대 0.8초, 다음 장면과 안 겹치게). (2026-10-30 「영상 컷이 뚝뚝」)
- 렉 방지: fps 필터 금지(setpts + 프레임 수 고정, concat 재인코딩), 0.05초 기준 겹친 프레임 0.
- 상위 2·3위가 끝에 시세·자료 캡처를 썼으면 직접 만든 카드(실제 값 확인·날짜·노란 형광펜, 폭 540px).

## 7. 소리
- 해설 음성: 앞뒤 무음만 자르고 통째로, 빠르기 그대로. **말 사이 쉼은 녹음 그대로(0.35초 넘는 쉼만 0.3초로)**, 해설 끝에 숨 0.15초 — 0.06초로 다 붙이면 숨 안 쉬고 몰아쳐 너무 빠름(2026-10-30 대표님). **해설 장면 길이 = 음성 길이(숨 포함).** 끝 해설은 음성 끝까지.
- **해설 나오는 동안 원본 소리 끔.** 대사 구간은 원본 소리 그대로.
- 완성본 약 **-10 LUFS**, 리미터. 해설·대사 둘 다 크게(한쪽만 키우지 않음).
- 해설 없는 속마음 장면은 읽을 만큼만(0.7초~). 무음 텀 길지 않게.

## 8. 썸네일
- 1·2·3위 썸네일을 받아 어떤 장면인지 보고, 원본에서 같은 장면을 찾아 후보 A(추천)·B·C. 대사 자막이 보이는 완성 화면 프레임, 얼굴 잘림 없음.
- 그 장면이 영상에 없으면 비슷한 해설 장면을 그 구간으로 옮겨 영상 안에 넣음(쇼츠 썸네일은 영상 프레임만 고를 수 있음).
- 추천은 터진 썸네일 표(장면·인물 수·조회수) 다수결로.

- 2026-11-02 · 쇼츠메이커.html은 **6단계(시작 → 분석·대본 → 제목·대본 확정 → 장면 맞추기 → 검수 → 만들기·전달)**, 토스 스타일. STEP 2의 「요청 복사」로 온 `[쇼츠 제작 요청]`에는 **반드시 이 형식으로만** 답한다(페이지가 읽어서 다음 단계를 채움):
  ```

  같은 원본 버전·상위 3개·공식 요약 몇 줄
  [제목 후보]

  C: …

  해시태그: …
  ```
  장면 줄의 v번호는 요청에 적힌 원본 번호, 얼굴 = 세로 위치 0(위)~1(아래). 분석 과정·비교표는 채팅에 따로 보여 주고, 페이지에 붙여넣을 블록은 위 형식 그대로 코드 블록 하나로.
