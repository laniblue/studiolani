# 다이내믹 편집 — 터진 쇼츠의 편집을 보고 따라 하기

자막만 얹은 영상은 밋밋하다. 터진 쇼츠는 4~6초마다 화면이 반응한다. 이 문서는 ① 레퍼런스 편집을 분석하는 법과 ② `edit.json`으로 그 편집을 재현하는 법을 다룬다.

## 1. 편집 분석 (무료)

1. `hook-research.md`의 검색으로 같은 주제·같은 장르에서 조회수 상위 쇼츠 2~3개를 고른다. 같은 원본을 다른 사람이 편집한 쇼츠가 있으면 그게 최고의 레퍼런스다. 실제로 이 스킬을 만들 때 쓴 영상은 한국어 편집본이 1,099만회였다.
2. 쇼츠를 열고 `javascript_tool`로 `assets/yt-frames.js`를 실행한 뒤 스크린샷을 찍는다. 0.75초 간격 32프레임이 한 장에 나온다. 뒷부분은 `START`를 바꾸고, 페이지를 새로 고친 다음 다시 실행한다.
3. 프레임 시트에서 아래 표의 항목을 세고, 몇 초에 무엇이 나오는지 적는다.

| 볼 것 | 시트에서 보이는 모습 |
| --- | --- |
| 펀치인 확대 | 앞 프레임보다 얼굴이 갑자기 크다. 몇 초마다 나오는지 센다 |
| 기울이며 확대 | 수평선이 기울어 있다. 보통 클라이맥스에 1~2번 |
| 천천히 밀기 | 몇 프레임에 걸쳐 조금씩 커진다. 긴 대사 구간 |
| 스티커 | ?, !, 💢, 땀방울 같은 글자 그래픽이 얼굴 주변에 뜬다 |
| 플래시 | 화면 전체가 하얗게 바랜 프레임 |
| 원본 글자 처리 | 박힌 자막·제목이 블러됐거나 가려졌는지 |
| 자막 | 위치, 색, 내레이션 여부 |

**효과음은 프레임으로 알 수 없다.** 소리를 들을 수 없으니 효과음은 시각 비트(확대·스티커·플래시)에 쇼츠에서 흔히 쓰는 조합으로 붙인다. 사용자에게 "효과음 위치는 추정"이라고 한 줄로 알린다.

## 2. 비트 잡기

전사(단어 시간)와 컷 지점(plan.json의 `joins_output_time`)을 옆에 두고, 장면마다 하나씩 고른다.

| 순간 | 카메라 | 효과 | 효과음 |
| --- | --- | --- | --- |
| 첫 훅 직전 | — | — | riser (훅 0.1초 전에 끝나게) |
| 돈·숫자를 말함 | 펀치인 1.2~1.3 | — | ding |
| 당황, "뭐라고?" | 확대 리셋 | ? 스티커 3개 | boing |
| 리액션 한마디 | 펀치인 1.25~1.35 | — | whoosh (말 0.05초 전) |
| 긴 설명·나열 | 천천히 밀기 1.0→1.15 (`"none"` ease, 4~5초) | — | 항목마다 tick |
| 짧은 반복("네네네") | 단계 확대 1.06 → 1.12 → 1.18 | — | pop |
| 클라이맥스·버럭 | 기울이며 확대 1.4~1.6, rotation ±3~5° | 플래시 + 흔들림 | impact |
| 컷 이음새 | 확대값 즉시 리셋(duration 0) | — | — |

- 확대값은 **컷 이음새에서 즉시 바꾼다.** 점프컷이 화면 변화를 가려 주니까 리셋이 티 나지 않는다.
- 펀치인은 0.1~0.15초, `power3.out`. 너무 느리면 "확대"가 아니라 "줌"처럼 보인다.
- 얼굴이 화면 밖으로 나가지 않게 `origin`을 얼굴에 둔다(영상 영역 기준 %). 스냅샷으로 확인한다.
- 같은 효과를 연속으로 쓰지 않는다. 확대 → 스티커 → 밀기 → 확대처럼 번갈아 쓴다.
- 4~6초에 한 번은 무언가가 움직이게 한다. 대사가 없는 구간도 포함이다.

## 3. edit.json → 적용

```bash
python3 $SK/build_edit.py <project> edit.json      # index.html의 카메라·효과음, fx.html의 플래시·스티커를 다시 쓴다
(cd <project> && npx hyperframes check)
npx hyperframes snapshot --at <펀치인>,<스티커>,<클라이맥스> --no-end   # 얼굴·자막이 잘리지 않았는지
```
형식은 `build_edit.py` 맨 위 설명을 따른다. 스티커 위치는 얼굴 주변에 두되, 자막 영역과 x 108–950 안전선 안에 둔다.

## 4. 효과음이 목소리를 가리지 않게

- 효과음 키트는 `sfx_synth.py`로 만들고, 모두 피크 -3 dBFS다. 기본 `data-volume`은 whoosh 0.3, pop 0.22, tick 0.25, ding 0.3, boing 0.3, impact 0.45, riser 0.25 정도로 시작한다.
- 효과음은 **대사 사이 빈 곳**에 둔다. 말 위에 꼭 둬야 하면 그 이벤트만 볼륨을 0.1~0.2로 낮춘다(`[t, "impact", 0.2]`).
- 렌더 후 `sfx_check.py`를 돌린다. 말 위에서 +3 dB 넘게 올리는 효과음은 볼륨을 내리거나 앞 빈틈으로 옮기고, 다시 렌더한다. 이 스킬을 만들 때도 처음엔 3개가 +4~8 dB였고, 고친 뒤 최대 +2.9 dB가 됐다.
- 배경음악을 쓸 때는 목소리보다 약 15 dB 낮게 시작하고, `/hyperframes-audio`로 대사 구간에서 덕킹한다.
