## ★ 파트마다 수정 요청 받기 (2026-10-24 대표님)
분석 → 각색(제목·대본) → 편집 스타일 → 제작 결과, 각 파트가 끝날 때마다 결과를 보여 주고 그 파트에서 수정 요청을 받는다. 수정은 그 파트만 고치고 다음 파트로 넘어가지 않는다. 오케이가 나면 다음 파트.

## 1. 분석 (가장 중요한 순서대로)
1. **같은 원본을 쓴 다른 버전들**(대표님이 준 참고 링크들)을 받아 자막을 시간과 함께 전부 뽑고 비교
   - 버전마다 제목·조회수·길이·사연 해설·정체 공개 시점·누가 무슨 말·감정선·끝 해설
   - 포인트 = **같은 내용, 다른 문구**. 공통 구조(N개 중 M개)를 찾는다
2. **편집 스타일**은 60fps로 한 프레임씩: 자막 등장 애니(통통 112%→92%→100%), 컷 전환, 화면 줌, 스티커, 소리
3. **같은 주제 터진 쇼츠**: 주제(검색어)는 대표님이 정한다(예: 웃긴 영상 / 웃긴 해외영상). 한·영·일로 검색, 100만+ 이면서 자막 각색 있는 것 최소 20개 → 제목 훅·자막 구성
4. 원본 화자: 목소리 높낮이 + 입 모양으로 확인. 추정 금지, 애매하면 글로 묻기

## 2. 각색 (대본)
- **원본(참고 영상) 형식 그대로, 글자(내용)만 바꾼다** — 줄 순서·종류(해설/사람/강아지 괄호)·말투 유지
- 버전들이 쓴 표현을 변형해서 쓰되 한 줄도 겹치지 않게(기계 대조, 비슷함 0.7 미만)
- 사연은 지어내지 않는다. 버전 하나에만 있는 세부(당뇨 등)는 확인 안 되면 안 씀
- 해설 반드시 포함: 첫 해설 짧게(2화면) · 3인칭 존댓말 · B급 감성 · 끝 해설로 마무리
- 사람 대사 = 친구한테 말하듯 반말 / 강아지 = 귀여운 아기 말투, 괄호
- 제목 2줄(1줄 8~12자 흰 / 2줄 6~10자 노랑) · 주인공(강아지·댕댕이·멍멍이 등 다양하게) 포함 · 결말 숨김 · 후보 여러 개 근거와 함께
- 대사 앞에 '…' 금지 · 말줄임은 항상 '..' (점 2개)
- **영상 만들기 전에 내용부터 공유 → 대표님 오케이 → 제작**
- 공유 형식: 코드 블록 — ① 참고 영상 내용(제목 + 화자 : 대사) ② 각색(제목 / 각색 내용 한 문장씩 줄바꿈 / 화자 : 대사). 화자는 "아내 : / 남편 : / 해설 : / 강아지 :" 만 — 단 주인공이 고양이면 "고양이 :", 사람이 집사면 "집사 :" 처럼 실제 대상 이름으로 (2026-10-25 대표님 "강아지가 아니라 고양이야"). 편집 메모 안 적음

## 3. 제작
- 길이 = 참고 영상 이하(30초 이내), 원본보다 길면 안 됨
- 원본 실제 말 구간에 자막 싱크 · 말·소리 빈 구간 없게 · 단어 중간에서 끊지 않기
- 템플릿 그대로 (zyjSK3IVsBQ): 위 검정 제목 칸 · 아래 검정 띠 · 자막 위치·글자 크기 동일 · 채널 표기(@멍냥한입) 넣지 않음
- 자막색 고정: 대사 제일 많은 사람(대사 줄 수, 같으면 여자) 노랑 #FFE006 · 다른 사람 #A5D8FF · 강아지 #8CE99A · 해설 흰색
- 폰트 고정: 해설 = 학교안심 알림장 B · 사람·동물 대사 = 배민 주아 · 외곽선 굵기 subStroke 18
- 자막 등장: 사람·강아지 대사 = 통통(elastic) · 하얀 해설 = 애니메이션 없이 바로
- 강아지 자막: 56px · 얼굴 가리지 않고 머리 바로 위(대표님이 몸통 등 따로 정하면 그 자리) · 강아지 움직임 따라감
- 정체 공개 순간만 피사체 쪽 줌인(pushTo) · 컷 줌인·핵심 단어 색 안 씀
- 자막 한 화면 최소 0.8초 · 말줄임은 '..' · 하얀 해설 자막엔 괄호 () 없음
- 효과음·배경음악 없음 · 하얀 해설 자막이 나오는 동안 영상 소리 끔
- 해설 음성: 파일마다 앞뒤 무음을 잘라 쉬는 틈 없이 줄줄이 붙이고, 각 해설 자막은 그 음성이 나오는 순간·길이에 맞춤
- 마지막 자막이 끝나면 영상도 끝 (음성 덧입힐 때도 항상)

## 4. 점검 → 전달
- 프레임 시트로 가림·잘림, 완성본 다시 받아써서 싱크·음성 위치 확인
- 영상 + 대사 텍스트(같은 버전) 전달, 폴더 띄우기. 업로드는 대표님이 직접
- 수정 요청은 요청한 것만, 한 번에(렌더 두 번 하지 않게 길이·화자·설정 먼저 확인)
