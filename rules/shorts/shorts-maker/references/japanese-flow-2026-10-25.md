# ★ 대표님 승인 일본어 쇼츠 제작법 (2026-10-25 「앞으로 일본어 영상은 이렇게, 한 번에」) — 일본어 쇼츠는 이 파일이 최우선 — **항상, 토씨 하나 틀림없이 이대로 진행**

완성 예시: `/Users/hyuna/스튜디오 라니_콘텐츠/shorts/아빠장난_ja/` (final-video.mp4 v10 · 작업 프로젝트 `_job2/work/make-v1/video` = 템플릿 겉모양이 다 들어간 HyperFrames 프로젝트, 다음 영상은 이걸 복사해서 a-roll·자막·제목만 바꾼다)

## 진행 순서 한눈에 (대표님 2026-10-25 「최종 진행 흐름 전부 기억해라」)
1. 입력 받기: 원본 영상 파일 + 참고(터진) 쇼츠 링크 + 템플릿. 링크만 오면 원본을 찾고, 못 찾으면 "확인 못 함" + 원본 요청
2. 원본 화질 확인 (0번) → 저화질이면 바로 말하고 고화질 요청
3. 분석 (1번) → 결과 보여 주기
4. 제목 후보 3개 → 대표님 선택 (2번)
5. 대본 → 코드 블록 공유 → 대표님 오케이 (3번)
6. 편집 계획(장면 순서·컷·대사 위치) → 미리보기 화면으로 점검 (4·6·7번)
7. 해설 음성 파일 받으면 음성 기준으로 장면·자막 맞추기 (5번)
8. 렌더 한 번 → 점검 (7번) → 전달 (8번)
- 길이: 대표님 원본 기준(원본 안에서 장면 순서만 참고 영상대로, 말 없는 구간·빈 구간은 컷).
- 파트마다 결과를 보여 주고 그 파트에서 수정 요청을 받는다. 수정은 요청한 것만, 대표님이 "렌더 하지 마" 하면 준비만.

## 0. 원본 화질 확인 (대표님 2026-10-25 「화질 구리면 말을 해. 고화질로 해야 한다고」)
- 작업 시작 전에 원본 해상도·비트레이트를 확인한다. 실제 화면 가로가 1080 미만이면(예: 406×720) 만들기 전에 바로 말하고 고화질 원본을 요청한다. 같은 영상의 고화질 파일이 이미 있으면 그걸 쓴다. 저화질을 몰래 키워서 쓰지 않는다.

## 1. 분석
- 참고(터진) 쇼츠 자막을 처음부터 끝까지 읽는다. 일본어 영상은 일본어 우선 글자 인식(ja-JP 먼저)으로 읽어야 안 깨진다.
- 참고 쇼츠와 원본의 **소리 파형을 맞춰서** 참고 쇼츠가 원본 몇 초에 어떤 대사·괄호 멘트를 달았는지 찾는다(화면 비교는 부정확).
- 원본에서 실제로 사람이 말하는 구간을 잰다(silencedetect). 장면 전환 지점도 잰다(scene detect).
- 같은 주제 100만+ 쇼츠(일본·한국)를 모아 자막·편집을 비교한다.

## 2. 제목
- 참고 영상 제목을 **같은 내용, 다른 표현(관점)** 으로 일본어 2줄 (예: 「아빠 놀리는 맛에 사는 아들」 → 「パパをいじるのが / 生きがいの息子」). 번역 아님, 새로 지어낸 다른 내용도 아님.
- 1줄 8~12자 흰 / 2줄 6~10자 연두, 주인공 포함, 결말 숨김, 터진 영상 제목과 단어 겹치지 않게. 후보 3개 + 추천 1개, 대표님이 고름.

## 3. 대본
- 참고 영상의 장면·순서·웃음 포인트를 그대로 두고 문장만 새로 쓴다(겹침 0.7 미만).
- **사람 대사는 실제로 말하는 순간에만.** 말 없는 구간엔 대사 금지. 말하는데 쓸 대사가 없으면 그 장면을 컷.
- 놀람·화남 대사 = 빨강. 해설 = 3인칭 존댓말, 짧게.
- 공유 형식: 코드 블록, `화자 : 일본어 (한국어 뜻)`, 제목 포함. 참고 영상의 괄호 리액션 멘트(?!)(ブチギレ)(ブーッ)(???) 등은 같은 순간에 맞춰 텍스트로 같이 적는다.
- 영상 만들기 전에 대본 오케이 받기.

## 4. 편집
- 장면 순서 = 참고 영상 순서(예: 망치 → 차 → 물 → 지하실). 첫 장면도 참고 영상처럼.
- 컷은 효과 없이 바로. **컷 시작·끝은 장면 전환 지점 안쪽** — 다른 장면이 1프레임이라도 끼면 안 됨(첫 프레임 차 장면, 하얀 벽 망치 3프레임 사고).
- 컷 이음새마다 소리 0.04초 페이드.
- 원본은 직접 잘라 이어 붙인다(ffmpeg trim/concat). make-shorts 자동 컷은 단어 경계로 늘려서 길이·싱크가 어긋나므로 쓰지 않는다.

## 5. 해설 음성 (대표님이 파일을 줌)
- 앞뒤 무음만 자르고 **파일을 쪼개지 않고 통째로**, 빠르기 그대로.
- **해설 장면 길이 = 음성 길이**로 컷 → 쉬는 틈 0 (0.25초 넘게 비는 곳 없게).
- **해설 자막은 음성 문장이 시작·끝나는 순간에 맞춘다**(음성에 자막을 맞춤).
- 해설 동안 원본 소리는 끈다. 단 대표님이 살리라고 한 소리(예: 스피커 경적)는 살린다.
- **해설 음성과 대사(원래 영상 소리) 둘 다 크게** — 둘 다 약 -10 LUFS 안팎, 최대치는 0dB 바로 아래(리미터). 한쪽만 키우지 않는다 (대표님 2026-10-25 「해설이랑 대사 둘 다 소리 크게」).

## 6. 겉모양 (대표님 템플릿 영상 실측 — _templates/spec.md)
- 위 검정 0~474px · 영상 474~1689px(가로 1080 꽉). 카톡 저장 원본은 위아래 검은 띠가 있으니 **실제 화면(약 y472)** 을 474에 맞춘다.
- 제목: Paperlogy 7Bold 121px, 줄간격 1.19, 1줄 흰색(글자 y185~292), 2줄 연두 #80FF04(y329~436).
- 해설: Paperlogy 8ExtraBold 104px 흰색, 외곽선 26px, 글자 y1311~1399, 등장 애니 없음.
- 사람 대사: **Paperlogy 8 ExtraBold**(2026-10-29 대표님 변경 · _templates/fonts/Paperlogy-8ExtraBold.ttf). Paperlogy에 없는 글자(、。？！·일부 한자)만 M PLUS Rounded 1c Black으로 채움. 104px(긴 줄만 900px 칸에 맞게 줄임), 외곽선 26px = 해설과 같은 굵기(2026-10-29 대표님), 글자 y1326~1404, 통통(elastic) 등장. 에이투지체는 일본어 글자가 없어서 못 씀.
- 색: 대사 많은 사람 #80FF04 · 적은 사람 #FFE006 · 강조·놀람 #FF0600.
- 긴 줄은 화면 900px 안에 들어가게 그 줄만 글자 크기를 줄인다.
- 효과음·배경음악 없음.

## 7. 점검 (렌더 전 미리보기 + 렌더 후)
- 이음새마다 앞뒤 프레임을 하나하나 본다.
- 완성본 소리를 재서 대사가 말하는 구간에 뜨는지, 비는 구간이 없는지 확인한다.
- 완성본을 받아써서 해설 음성 위치·내용을 확인한다.
- 템플릿 영상과 숫자(제목·자막 위치·크기·외곽선)를 비교한다.
- 마지막 자막이 끝나면 영상도 끝.
- 렌더는 다 확인하고 **한 번만**. 수정은 요청한 것만.

## 8. 전달
- 영상 + 썸네일 + 대사 텍스트(제목 · 화자 : 일본어 (한국어 뜻)) + 업로드 문구(元動画 출처 — 모르면 비워 두고 말하기).
- 해시태그: **#面白い動画 #海外面白動画 항상 넣기 · 영문 #shorts 항상 빼기** (대표님 2026-10-25).
- 썸네일: **대사 자막이 있는 장면**(대표님 2026-10-26 「난 대사 있는 장면으로 하고 싶어」) — 터진 버전 썸네일들과 비교해 장면을 고르고, 위 제목 + 그 장면의 대사 자막 한 줄, 자막 등장 애니가 끝난 또렷한 프레임(흐린 프레임 금지). 후보 2~3장 보여 주고 고르게.
