## 0. 질문 (한 번에, AskUserQuestion 최대 4문항)

질문하기 전에 먼저 찾는다. 첨부 파일, 현재 폴더, 바탕화면, 다운로드 폴더에서 영상·음악·효과음 파일(`*.mp4 *.mov *.mp3 *.wav`)을 찾아보고, 찾은 것은 묻지 않는다. 사용자가 이미 말한 것도 묻지 않는다.

1. **어떤 영상?** 파일을 못 찾았을 때만 묻는다.
2. **스타일**
   - 기본 쇼츠 스타일(추천): 상단 검정 바에 2줄 제목, 말하는 사람 옆 외곽선 자막, 확대·효과음 같은 다이내믹 편집
   - 레퍼런스 따라하기: URL을 받는다
   - 자막만 깔끔하게: 헤더 없이 하단 중앙 자막
3. **컷 강도**
   - 무음만(추천): 말과 웃음 포인트는 전부 살린다
   - 무음 + 말더듬·재촬영 정리
   - 30초 하이라이트
4. **터지는 쇼츠 분석**
   - 무료 분석(추천): 브라우저로 유튜브를 검색해서 조회수 상위 쇼츠의 제목 패턴과 화면을 본다. 크레딧 0
   - vidIQ 정밀 분석: 채널 평균 대비 떡상 정도까지 본다. 크레딧 사용(호출당 약 5)
   - 건너뛰기

효과음은 기본으로 넣는다. 파일이 없으면 `sfx_synth.py`로 합성한다(다운로드 없음). 배경음악은 파일이 있을 때만 묻고, 없으면 배경음악 없이 간다고 한 줄로 알린다.
자막 언어는 묻지 않는다. 한국어 영상이면 한국어로 받아쓰고, 외국어 영상이면 한국어로 번역·각색한다.

## 2. 영상 먼저 보기 (판단의 근거)

```bash
ffmpeg -i raw.mp4 -vf "fps=1.5,scale=144:-1,tile=10x14" -frames:v 1 sheet.jpg
```
한 장으로 이어 붙인 화면(contact sheet)을 직접 보고 다음을 기록한다.
- 몇 명이 말하는지, 화면 밖 인물이 있는지와 그 방향
- 원본에 박힌 자막·제목이 있는지와 그 위치. 박힌 자막은 번역의 1순위 원문이다. 확대해서 읽는다(`crop=W:110:0:Y` 띠를 이어 붙이면 잘 보인다).
- 장르: 콩트, 브이로그, 정보, 리뷰 등. 콩트라면 반복·말더듬이 개그일 수 있다.

## 3. 컷

```bash
python3 $SK/autocut.py raw.mp4 --out cut-v1.mp4 --plan plan.json
```
- 0.6초 넘는 무음만 잘라서 앞뒤로 0.2초 숨을 남긴다. 속삭임은 자동으로 보호한다. `notes`를 확인한다.
- "말더듬·재촬영 정리"를 골랐으면 전사를 보고 같은 문장의 반복 테이크를 찾는다. 마지막으로 완전하고 자연스럽게 말한 테이크를 남긴다. 다만 연출된 반복(개그)은 남기고, 애매하면 사용자에게 묻는다. 추가 컷은 plan.json의 `cuts`에 넣고 다시 렌더한다.
- 30초 하이라이트는 훅 → 전개 → 펀치라인 순서가 유지되는 구간을 골라 이어 붙인다.
- **재전사 검사**: 원본과 cut-v1을 같은 엔진으로 전사해서 단어 단위로 비교한다. 빠진 말이 컷 지점과 겹치면 진짜 누락이다. 그 컷을 줄이고 다시 만든다.
```bash
npx hyperframes transcribe raw.mp4 -d <tmpA> --engine whisper
npx hyperframes transcribe cut-v1.mp4 -d <tmpB> --engine whisper   # 둘 다 flat word array
```

## 4. 터지는 쇼츠 분석 → 후킹 (선택)

`references/hook-research.md`를 읽고 그대로 따른다. 요약하면 이렇다.

**두 번째 질문**: 한 번의 AskUserQuestion으로 ① 각색 관점(관점마다 헤더 제목 포함)과 ② 기획 제안(예: 앞 2.7초 자르고 갈등부터 시작)을 묻는다. 추천 1개에 이유를 한 줄 붙인다. 분석을 건너뛰었어도 후보 3개는 직접 만들어 묻는다.

## 5. 자막 · 헤더 만들기

**captions.json**은 cut-v1 전사의 단어 시간을 기준으로, **고른 관점에 맞게 각색해서** 직접 쓴다(`references/hook-research.md`의 '각색 = 관점 정하기').
- 한 줄에 2~4어절, 의미 단위로 자른다. 조사가 혼자 남거나 고유명사가 쪼개지면 안 된다.
- `s`는 첫 단어 시작, `e`는 다음 줄 시작 직전이다. 대사가 끝나고 0.7초 넘게 남기지 않는다.
- 화자마다 `who`를 붙이고 색과 위치를 정한다. 기본값:
  - 화면 밖 상대(예: 창구 직원): `#ffe94d`, box `[90,540,852,300]`, 오른쪽 정렬
  - 화면 속 인물: `#ffffff`, box `[116,1060,820,240]`, 왼쪽 정렬
  - 한 명이면 흰색, box `[116,1060,848,240]`, 가운데 정렬
  - 속마음 `IN`: `#9be7ff`, size 60, 괄호로 감싼 문장, box `[116,1330,834,110]`, 가운데 정렬. 내레이션 `NA`: `#6cf542`, 같은 box. 같은 인물의 대사와는 동시에 띄우지 않고, 상대방 대사 중이나 빈틈에 띄운다
- 원본에 박힌 제목 카드나 얼굴과 겹치면 box를 옮긴다. 근거는 스냅샷이다.

```bash
python3 $SK/blur_regions.py cut-v1.mp4 cut-v1-clean.mp4 --region x,y,w,h,start,end   # 원본에 박힌 외국어 제목 카드 등이 있으면 (delogo)
python3 $SK/scaffold.py <name> --video cut-v1-clean.mp4 --line1 "<1줄>" --line2 "<2줄>" [--lift <px>] [--header-style black|sky]
python3 $SK/build_captions.py captions.json <name>/compositions/captions.html
```
- 박힌 자막 띠가 영상 위쪽에 있으면 `--lift`를 쓴다. 띠 하단(1080폭 기준 px)에서 기본 크롭(세로 영상은 480)을 뺀 값에 여유를 조금 더한다. 이번 예시는 띠 하단이 약 500px이라 lift 53을 썼다.
- 헤더는 검정이 기본이다(`--header-style sky`면 하늘 그라데이션). scaffold가 효과음 키트(`sfx/`)와 빈 편집 레이어도 만든다.
- `font.file`은 scaffold가 출력한 `font_rel`(예: `fonts/Display.ttf`)과 맞춘다.
- 박힌 글자 영역은 빨간색 등 눈에 띄는 색의 픽셀을 프레임마다 세어 bbox와 시간 범위를 구하고, 12px 여유를 둔다. `delogo`가 기본이고, 메운 부분에는 약한 블러가 자동으로 들어간다.
- 스타일 "자막만 깔끔하게"를 골랐으면 scaffold의 헤더 호스트를 지우고, 영상을 전체 화면으로 펼치고, 자막을 하단 중앙 한 화자 스타일로 만든다.
- 레퍼런스 스타일이면 레퍼런스의 헤더 비율·색·자막 위치에 맞게 `header.html`과 box를 조정한다. 동일하게 해 달라고 하면 최대한 같게 맞추고, 못 맞춘 부분은 무엇인지 말한다(예: 구름 사진이 없음).

## 5.5 다이내믹 편집 (기본으로 한다)

`references/dynamic-edit.md`를 읽고, 분석한 레퍼런스 편집과 전사·컷 지점을 보며 `edit.json`을 쓴다. 4~6초마다 화면이 반응하게 한다.
- 리액션에는 펀치인, 긴 대사에는 천천히 밀기, 클라이맥스에는 기울기·흔들림·플래시, 당황하는 장면에는 스티커를 쓴다.
- 확대 리셋은 컷 이음새에 둔다. 효과음은 시각 비트에 붙이고, 대사 사이 빈 곳에 둔다.
```bash
python3 $SK/build_edit.py <name> edit.json
```
스냅샷으로 펀치인·스티커·클라이맥스 프레임을 보고, 얼굴이나 자막이 잘리지 않았는지 확인한다.

## 6. 최종 QA (렌더 전에 반드시)

```bash
(cd <name> && npx hyperframes check)                     # 오류·경고 0개까지
python3 $SK/qa.py --video <name>/a-roll.mp4 --plan plan.json --captions captions.json --fix
python3 $SK/build_captions.py captions.json <name>/compositions/captions.html   # --fix로 바뀌었으면 다시 생성
```
`qa.py` 검사 항목:
- 컷 이음새의 첫 음절·마지막 음절
- 영상 시작과 끝
- 자막 싱크
- 컷을 넘겨 남는 자막(자동 수정)
- 겹침과 너무 빠른 자막
- 음량(LUFS·피크)

"listen" 항목은 그 시점을 들어 보고 판단한다. 번역 자막의 의미 단위 경계라면 그대로 둔다.

**잘린 요소 검사**: 미리보기를 띄우고(`npx hyperframes preview --background`), 브라우저 창에서 `http://localhost:<port>/api/projects/<name>/preview?_t=<n>`을 연다. 그다음 `javascript_tool`로 `assets/measure-safe.js` 내용을 실행한다. 자막 글자가 외곽선까지 포함해서 x 108–950, y 480(헤더 아래)–1440 안에 있는지, 2줄 이상으로 줄바꿈되는 자막이 무엇인지 알려 준다.

**눈으로 확인**: `npx hyperframes snapshot --at <첫 자막>,<화자 바뀌는 곳>,<가장 긴 자막>,<끝> --no-end`로 찍은 한 장 이미지를 직접 보고, 겹침·가림·잘림을 고친다.

배경음악이 있으면 `/hyperframes-audio`로 넣는다. 목소리보다 약 15 dB 낮게 시작하고, 대사 구간에서는 덕킹한다.

## 7. 미리보기 · 렌더 · 썸네일

```bash
(cd <name> && npx hyperframes preview --background)        # 브라우저 창으로 열어 보여 준다
(cd <name> && npx hyperframes render --quality high --output final-video.mp4)
ffprobe -v error -show_entries stream=width,height,r_frame_rate:format=duration final-video.mp4
```
- 렌더가 끝나면 결과 파일의 해상도·길이·오디오를 확인하고, 프레임 몇 장을 뽑아 직접 본다.
- **효과음 검사**: `python3 $SK/sfx_check.py --voice <name>/a-roll.mp4 --final final-video.mp4 --index <name>/index.html`. 말 위에서 +3 dB 넘게 올리는 효과음은 볼륨을 낮추거나(`edit.json`에서 `[t, "impact", 0.2]`) 옮긴 뒤 다시 렌더한다.
- **썸네일**: 표정이 가장 강한 순간을 스냅샷 3~5장 중에서 고른다. `assets/thumbnail.html` 맨 위 주석대로 `thumb/`를 만들고, `npx hyperframes snapshot thumb --at 0.5 --no-end`로 PNG를 얻는다. 원본에 박힌 자막 띠가 있으면 프레임을 lift만큼 크롭해서 쓴다.
- 결과물은 SendUserFile로 영상과 썸네일을 보낸다.

## 8. 마무리 보고 (짧게)

- 결과 파일: final-video.mp4(해상도·길이), 썸네일
- 업로드 제목, 설명 한 줄, 해시태그. 복사해서 쓸 수 있게 코드 블록에 넣는다.
- 컷: 몇 초에서 몇 초가 됐는지, 보호한 속삭임이나 일부러 남긴 반복
- 편집: 레퍼런스에서 가져온 기법과 들어간 위치. 효과음 위치는 소리를 듣고 정한 게 아니라 화면 비트에 맞춘 추정이라고 말한다.
- QA 결과와 고친 것. 남은 한계는 그대로 말한다(예: 구름 사진 없음, 화자 판단이 애매한 줄).
- 다음에 해 볼 만한 것은 한 줄만 쓴다(예: 음량 -14 LUFS 버전).

## 원칙
- **숫자와 사실을 지어내지 않는다.** 조회수, 영상에 없는 결말, 박힌 자막과 다른 숫자는 쓰지 않는다.
- **판단은 직접 보고 들은 것에 근거한다.** contact sheet, 스냅샷, RMS 측정을 쓴다. Whisper 타임스탬프만 믿고 컷하지 않는다.
- **개그와 연출은 살린다.** 컷 강도는 사용자 선택을 따르되, 웃음 포인트를 자르면 안 된다.
- **인스타·쇼츠 UI를 피한다.** 핵심 글자는 x 108–950, 하단 480px(계정명·캡션)와 오른쪽 버튼 줄 밖에 둔다.
