# 컷별 이미지 프롬프트 형식

컷마다 아래 형식으로 하나씩 낸다. 각 프롬프트는 복사하기 쉽게 코드 블록에 담는다.

```
[CUT 4]
{스타일 블록: 캐릭터 파일 그대로}
{등장하는 캐릭터의 고정 블록: 캐릭터 파일 그대로}

Shot: {연출표의 샷}, {앵글}
Action: {한 가지 행동}
Expression: {눈, 입, 부호, 몸짓}
Background: {배경 또는 단색 지정}
Composition: {인물 위치, 예: 화면 왼쪽 1/3, 오른쪽 위는 말풍선 자리로 비움}
No text, no letters, no speech bubbles.
```

- 말풍선이 들어갈 자리는 Composition에 반드시 비워둔다.
- 캐릭터 레퍼런스 이미지를 첨부할 수 있는 툴이라면, 첫 줄에 "첨부한 캐릭터 시트와 같은 캐릭터"라고 쓴다.
- 쓰는 이미지 툴이 영어 프롬프트를 더 잘 알아듣는다면 Action/Expression/Background도 영어로 쓴다. 이건 캐릭터 파일의 "이미지 툴" 항목을 따른다.
