# 연출 규칙

## 기본 규칙
- 같은 샷 크기를 3컷 연속으로 쓰지 않는다. 샷 종류: 풀샷, 니샷, 바스트, 클로즈업, 익스트림 클로즈업(눈, 손, 물건).
- 10컷 기준 구성: 풀샷 1개 이상(공간 설정), 클로즈업 2개 이상, 인물이 없는 컷(물건, 손, 배경) 1개 이상.
- 1컷은 누가 어디에 있는지를 보여준다. 풀샷이나 니샷을 쓴다.
- 펀치라인 직전 컷은 "멈칫"하는 컷이다. 대사를 없애거나 "…"만 쓰고, 배경은 단색으로 비운다.
- 펀치라인 컷은 클로즈업이나 바스트로 잡고, 배경은 단색이나 집중선 같은 효과로 단순하게 한다.
- 앵글은 정면만 쓰지 않는다. 10컷 중 최소 3컷은 측면, 3/4, 위에서, 아래에서, 어깨 너머 중에서 고른다.
- 감정이 커지면 샷도 가까워진다. 감정이 식거나 상황을 정리할 때는 샷이 멀어진다.
- 한 컷에는 한 가지 행동만 넣는다. 행동이 두 개면 컷을 나눈다.
- 표정은 형용사 하나로 끝내지 않는다. 눈, 입, 땀이나 홍조 같은 부호, 몸짓까지 쓴다. (나쁜 예: 놀람 / 좋은 예: 눈 동그랗게, 입 작게 벌림, 어깨 들썩)
- 배경은 이야기에 필요한 컷에서만 그린다. 나머지 컷은 단색이나 단순화한 배경을 쓴다. (그림 품이 줄고 가독성이 오른다)
